\# 该文件夹下所做的是使用模拟退火算法解决旅行商问题

\# 本人将完整的实验步骤分为4个阶段，分别对应version\_1、version\_2、version\_3、version\_4

\# version\_1中的模型具备模拟退火算法的基本数据处理结构，能进行路径迭代下降，但功能不完善

\# version\_2中完善了状态生成函数，并解决了上一阶段中的一些逻辑错误，梯度下降效果明显

\# version\_3中完善了状态选择函数，以及所有必要的处理流程，程序运行结果符合该算法的预期

\# version\_4是最终版本，在version\_3的基础上调整了参数，并引入了“早停”机制

\# 至此，该算法针对旅行商问题的求解已完成，各个版本的运行结果也包含在文件夹内

\# 注意：城市规模是算法模型参数中的一种，可输入不同的城市规模进行求解
